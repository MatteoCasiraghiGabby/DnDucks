    Build plan

    Future Backend Roadmap

    Phase 1 — Static frontend prototype

    HTML/CSS/JS, localStorage, demo dashboard, notes, characters, items, calendar, files placeholder, and AI placeholder.

    Phase 2 — User accounts

    Recommended stack: React or Next.js, Node.js/Express or Next.js API routes, PostgreSQL or Supabase, and Supabase Auth, Clerk, Firebase Auth, or Auth.js.

    Phase 3 — Database models

    Tables: users, campaigns, notes, characters, locations, factions, quests, items, maps, calendar_events, files, document_links, and ai_suggestions.

    Phase 4 — File uploads

    Add storage, map image support, PDFs/documents, and attachments for notes, NPCs, locations, and campaigns.

    Phase 5 — Rich document editor

    Add markdown or rich text, autosave, document links, tags, search, and backlinks like a campaign wiki.

    Phase 6 — AI assistant

    Use embeddings, vector search, and RAG while limiting model access to user-approved campaign data.

    Phase 7 — Maps

    Upload maps, add pins, link pins to notes, NPCs, locations, quests, and encounters, then save annotations.

    Phase 8 — Collaboration

    Support multiple users per campaign with Dungeon Master, Player, and Viewer roles plus private DM notes.
